# mnm2_pdm
Projeto serviços de lavação. Programaçao para Dispositivos Moveis

Contexto: Aplicação PWA na arquitetura SPA WS para consulta de ofertas de serviços e agendamento/reagendamento de um serviço ofertado.

Objetivo: Oferecer serviços com desconto para um cliente cadastrado, permitindo consultar, agendar e reagendar uma ordem de serviço.

Tecnologias: HTML5, Bootstrap 5.3.8, Javascript, npm_axios
